# ワイド画像検索

複数の画像データベースを**同時に横断検索**できる、ブラウザだけで動く画像検索アプリです。
写真・イラスト・美術作品・宇宙写真・歴史資料など、幅広い画像をまとめて探せます。

## 使い方

`index.html` をブラウザで開くだけです（サーバー・インストール不要）。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。

ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 機能

### キーワードで検索
- 以下のソースを並列で検索し、結果を交互に混ぜて表示します（無限スクロール）

| ソース | 内容 | APIキー |
| --- | --- | --- |
| Openverse | Flickr・Wikimedia・美術館など数十サイトの8億点以上のCC画像 | 不要 |
| Wikimedia Commons | 写真・図版・地図・歴史資料など1億点以上（日本語検索に強い） | 不要 |
| NASA | 宇宙・天体・ロケット・地球写真 | 不要 |
| シカゴ美術館 | 絵画・浮世絵・写真・工芸 | 不要 |
| メトロポリタン美術館 | オープンアクセス作品（初期状態はオフ） | 不要 |
| Pixabay / Unsplash / Pexels | 商用利用可のストック写真・イラスト | 必要（無料） |

- フィルタ: 向き（横長・縦長・正方形）、商用利用可のみ
- 表示切替: タイル / グリッド、ダークモード
- 画像の詳細表示（作者・ライセンス・サイズ）、元画像を開く、ダウンロード、URLコピー
- Google・Bing・Yahoo! JAPAN・DuckDuckGo・Yandex・Pinterest・Flickr・pixiv・いらすとや・ColBase へのワンクリック横断検索
- 検索履歴、URL共有（`?q=キーワード`）

### 画像で検索（逆画像検索）
- 画像URLを入力 → Google レンズ / Bing / Yandex / TinEye / SauceNAO / ascii2d で一括検索
- ローカル画像のドロップ・貼り付けにも対応（各サービスへ渡すためのコピー／保存を補助）
- 検索結果の画像から「この画像で類似検索」も可能

## APIキーの設定

右上の ⚙ から Pixabay / Unsplash / Pexels の無料APIキーを登録すると、検索対象が増えます。
キーはブラウザの localStorage にのみ保存され、外部には各APIへのリクエスト以外で送信されません。

## 注意

各画像の著作権・ライセンスは掲載元に従います。利用前に掲載ページで必ず確認してください。

## ファイル構成

```
index.html      画面
css/style.css   スタイル
js/sources.js   各画像APIへの接続と結果の正規化
js/app.js       検索・表示・ライトボックス・逆画像検索などのUIロジック
```
